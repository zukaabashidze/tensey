# TSM Designs — საიტის რედაქტირება

არქივი მთლიანად ამოიღე ერთ საქაღალდეში. სანახავად გახსენი `index.html`.
გამოსაქვეყნებლად ჰოსტინგზე ატვირთე მთელი საქაღალდის შიგთავსი, ფაილების სახელებისა და სტრუქტურის შენარჩუნებით. Node.js ან აწყობა საიტის მუშაობას არ სჭირდება.

## სად რა იცვლება

- `index.html` — მთავარი გვერდის ინგლისური ტექსტები, სექციები და ძირითადი დიზაინი.
- `language.js` — ქართული ტექსტები. მარცხენა მხარეს ინგლისური ტექსტია, მარჯვენაზე ქართული. ინგლისური ტექსტის შეცვლისას შესაბამისი გასაღებიც შეცვალე. მთავარი ქართული სათაური ამავე ფაილის ბოლოში, `heading.innerHTML`-ის წესშია.
- `site-config.js` — ელფოსტა, ტელეფონი და Facebook/Instagram/Discord-ის ზუსტი ბმულები. სოციალური ბმულები ჯერ ცარიელია; ჩასვი სრული `https://...` მისამართები. შემდეგ აიქონები ავტომატურად გააქტიურდება.
- `thumbnails.html`, `logos.html`, `banners.html`, `posters.html` — შესაბამისი კატეგორიის გვერდის ტექსტები.
- `portfolio-images.js` — პორტფოლიოს ფოტოების მისამართები და მთავარი ბარათების ფოტოები.
- `assets/portfolio/` — პორტფოლიოს სურათები.
- `assets/portfolio/logo.png` — საიტის ლოგო და ბრაუზერის ხატულა.
- `hero-collage.css` — მოძრავი ფონი; საწყისი სურათია `assets/portfolio/xx.png`. ამ სურათის ზომა და განლაგება განსაზღვრავს კადრების კოორდინატებს. სხვა კოლაჟით ჩანაცვლება ამ კოორდინატების გადაწყობასაც მოითხოვს.
- `interactions.css` — hover ეფექტები, სოციალური აიქონების კომპაქტური ფონი და საერთო დამატებითი სტილები.
- `site.js` — მენიუ, კონტაქტები, ფორმა და ფოტოების გახსნა/დახურვა.

ტექსტები შეცვალე UTF-8 კოდირების მქონე რედაქტორით. HTML-ში შეინარჩუნე ტეგები და `id`/`class` ატრიბუტები. JavaScript-ში შეინარჩუნე ბრჭყალები და მძიმეები; ერთმაგ ბრჭყალებში ჩაწერილი ტექსტის შიგნით აპოსტროფი ჩაწერე ასე: `\'`.

## პორტფოლიოს ფოტოების მართვა

მართვის გვერდი პაროლითაა დაცული: `/manage`-ზე შესვლისას გადამისამართდები `/login` გვერდზე. ავტორიზაციის მონაცემები და პაროლის ჰეში ინახება მხოლოდ `instance/admin-auth.json` ფაილში; ეს ფაილი Git-ში იგნორირებულია. არ ატვირთო ის საჯარო საცავში და ჰოსტინგზე იმავე ფაილი უსაფრთხოდ დაამატე. სერვერზე HTTPS-ის ჩართვისას დააყენე `SESSION_COOKIE_SECURE=1`.

გაუშვი Flask-ის საიტი და გახსენი `/manage`. აირჩიე პროექტის სახელი, დიზაინის ტიპი და ატვირთე PNG, JPG, JPEG ან WEBP ფაილი (ან ჩასვი სურათის URL). შენახული ფოტო არჩეული ტიპის გალერეაში დაემატება; წაშლის ღილაკი მას გალერეიდანაც ამოიღებს. ფოტოები ინახება `static/uploads/` საქაღალდეში, ხოლო მონაცემები — `database.db`-ში. ჰოსტინგზე ატვირთული ფოტოებიც და მონაცემთა ბაზაც სერვერზე უნდა იყოს შენახული.

## შემოწმებული ფუნქციები

შემოწმებულია JavaScript-ის სინტაქსი, შიდა ფაილები და ბმულები, პორტფოლიოს ფოტოების მისამართები, ოთხივე გალერეა, ქართული/ინგლისური გადართვა, ცარიელი ფორმის ვალიდაცია, მობილური მენიუს გახსნა/დახურვა, ფოტოს გახსნა Enter-ით და დახურვა Escape-ით, ფოკუსის დაბრუნება და განლაგება 320/390 პიქსელსა და დესკტოპის ზომაზე. შემოწმებულ გვერდებზე JavaScript-ის შეცდომები არ დაფიქსირებულა.

Google Fonts ინტერნეტს იყენებს; მისი მიუწვდომლობისას საიტი სისტემურ შრიფტს აჩვენებს. რიცხვები, შეფასებები და სხვა შინაარსობრივი მტკიცებები თავდაპირველი საიტიდანაა შენარჩუნებული — გამოქვეყნებამდე ჩაანაცვლე შენი რეალური მონაცემებით.

შემდგომი ცვლილებების შემდეგ გადაამოწმე ორივე ენა, მობილური განლაგება და ბმულები. შემოწმება ვერ იძლევა გარანტიას ყველა ბრაუზერსა და მომავალ ცვლილებაზე.
